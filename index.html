Research

I build data systems for the AI era, with research spanning two complementary paths:

Vector search. I design and evaluate vector search techniques inside modern database systems, with an emphasis on filtered and filter-agnostic vector search, high-dimensional embedding operators, and indexes that integrate efficiently with relational query processing and stream processing.

Declarative agentic AI data systems. I work on declarative abstractions for composing and optimizing LLM/agentic pipelines, treating prompts and agents as first-class, optimizable operators so that data systems can plan, chain, and adapt AI-driven workloads automatically.
